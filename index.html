NIGHTGLEAN STUDIO

独立开发 · 原生实现 · 先把「能不能不这样做」问一遍

一个很小的独立工作室，做 Android 应用与工程实验。不追框架，不堆依赖，尽量让每一条构建链路都能被自己读懂。

项目

  • 拾光 OneStar

    0.12.x · targetSdk 37

    一天记一笔心情，累积成一片手绘星图。桌面小组件、心情曲线、年度长图海报。

    纯 Java 加 Canvas 自绘，无 Gradle、无 AndroidX、无第三方 SDK；aapt2 + javac + d8 + apksigner 手工串起构建，JNI 层用 zig cc 编译。

  • AppFunction Guard

    alpha · Kotlin

    Android 16 的 AppFunctions 让 AI Agent 能直接调用 App 内的函数，这个库补上平台没给的逐函数授权、限流、参数校验与审计链路。

    单一拦截点插在平台与业务逻辑之间，minSdk 26，MIT。

  • moltdisk 蜕冗

    v0.1.0 · Rust

    磁盘体检工具：找出能由源码重建的构建产物，算体积、排序，并给出「凭什么可删」的证据。它自己不删任何东西。

    Rust 2021，MSRV 1.80；没有删除代码路径，传 -y 直接报错。

  • Marvis · Persona Spec

    v3 · Python lint

    一份能被程序检查的人格规范：30 格台词位、20 条禁句、一个能跑的 lint 脚本、10 条基准测试。

    CI 里做两段式接入，先出灰阶报告，再上门禁。

做事方式

原生优先
界面用 Canvas 逐帧画，不套 WebView，不为了快而牺牲可控。
依赖克制
能自己写的一行，就不引入一个包。构建链的每一环都要说得清做了什么。
可复现
命令行能编译出同一种 APK，构建过程不依赖 IDE 的隐式魔法。
文档写实
README 里同时记限制、踩坑和已知问题，不只写亮点。
